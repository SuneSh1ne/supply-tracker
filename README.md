# Сервис учёта поставок

Консольное приложение для учёта поступлений товаров на склад от поставщиков.

## Возможности
- Регистрация новых поставок с валидацией данных.
- Расчёт итоговой стоимости поставки.
- Определение статуса поставки (принята, ожидает оплаты, отклонена).
- Поиск поставок по названию поставщика или товара.
- Фильтрация поставок по статусу.
- Сортировка поставок по дате (с использованием lambda-функции).
- Сохранение и загрузка данных в формате JSON с обработкой исключений.

## Структура проекта
- `main.py` – точка запуска приложения, основное меню.
- `deliveries.py` – функции для работы с поставками (добавление, поиск, фильтрация, сортировка, валидация).
- `storage.py` – функции сохранения и загрузки данных (JSON, контекстные менеджеры).
- `utils.py` – вспомогательные функции для безопасного ввода данных пользователем.
- `data/` – каталог для хранения JSON-файлов с данными (`deliveries.json`).
- `tests/` – автоматизированные тесты (`pytest`).

## Требования
- Python 3.8+
- `pytest`
- `flake8`
