# Сервис учёта поставок (ООП версия)

Консольное приложение для учёта поступлений товаров на склад от поставщиков, построенное на принципах объектно-ориентированного программирования.

## Основные сущности (Классы)
- **`Supplier`** (Поставщик) — хранит ID и название.
- **`Product`** (Товар) — хранит ID, название и базовую цену.
- **`Delivery`** (Поставка) — связывает объекты `Supplier` и `Product`, хранит количество, дату, статус оплаты и отмены. Содержит методы расчёта стоимости (`calculate_total_cost`) и определения статуса (`get_status`).

## Взаимодействие объектов
Объект `Delivery` не хранит названия поставщика и товара строками. Вместо этого он содержит прямые ссылки на объекты `Supplier` и `Product`. При сохранении в JSON объекты преобразуются в ID связей, а при загрузке — восстанавливаются через поиск в коллекциях (метод `Delivery.from_data`).

## Структура проекта
- `main.py` – точка запуска, консольный интерфейс.
- `models/` – пакет с классами предметной области (`Supplier`, `Product`, `Delivery`).
- `storage.py` – сериализация и десериализация объектов в JSON.
- `utils.py` – безопасный ввод данных пользователем.
- `data/` – JSON-файлы (создаются автоматически).
- `tests/` – автоматизированные тесты `pytest`.
