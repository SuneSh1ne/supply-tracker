# Сервис учёта поставок

## Назначение

Приложение предназначено для учёта поставок товаров на склад:
регистрация поступлений от поставщиков, проверка данных,
расчёт стоимости и определение статуса поставки.

## Целевая аудитория

- Кладовщики и сотрудники склада.
- Менеджеры по закупкам.
- Администраторы, ведущие справочники поставщиков и товаров.

## Предметная область

Складская логистика. Учёт поступлений товаров от поставщиков:
фиксация факта поставки, контроль количества и стоимости,
отслеживание статуса.

## Основные сущности

- Поставщик
- Товар
- Поставка
- Позиция поставки

## Основные функции

- Регистрация новой поставки.
- Проверка корректности данных поставки (валидация).
- Расчёт итоговой стоимости поставки.
- Определение статуса поставки.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
