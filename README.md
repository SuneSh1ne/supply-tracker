# Supply Tracker — сервис учёта поставок

Консольное и веб-приложение для учёта поступлений товаров на склад
от поставщиков. Проект развивается поэтапно в рамках серии практических
работ по Python и Django.

## Назначение

Приложение предназначено для складской логистики:
- фиксация поступлений товаров от поставщиков;
- контроль количества и стоимости;
- отслеживание статусов поставок (принята / ожидает оплаты / отменена);
- ведение справочников поставщиков и товаров.

## Предметная область

Основные объекты предметной области:
- **Поставщик** (`Supplier`) — организация, поставляющая товары;
- **Товар** (`Product`) — единица учёта с фиксированной ценой;
- **Поставка** (`Delivery`) — факт поступления товара от поставщика,
  связанный с объектами `Supplier` и `Product`.

## Технологический стек

- **Python 3.12** — язык реализации;
- **Django 5.2** — веб-фреймворк;
- **Bootstrap 5** — оформление веб-интерфейса;
- **pytest** — автоматизированные тесты;
- **flake8** — проверка качества кода.

## История развития

| Этап | Что реализовано |
|------|-----------------|
| ПР1 | Начальный сценарий: валидация, расчёт стоимости, статус |
| ПР2 | Коллекции, JSON, обработка исключений, модули, тесты |
| ПР3 | ООП: классы `Supplier`, `Product`, `Delivery` |
| ПР5 | Django-веб-интерфейс, Bootstrap, маршрутизация |
